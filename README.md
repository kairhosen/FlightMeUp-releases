# FlightMeUp

Lance d'un clic les outils compagnons de Microsoft Flight Simulator : **Navigraph Charts** (avec import du dernier vol SimBrief), **BeyondATC** (démarrage automatique du vol) et **AutoFPS**. Fenêtre compacte, thème clair / sombre, français, anglais et espagnol.

Launches Microsoft Flight Simulator companion tools in one click: **Navigraph Charts** (with your latest SimBrief flight imported), **BeyondATC** (flight started automatically) and **AutoFPS**. Compact window, light / dark theme, French, English and Spanish.

> **Bêta / Beta** : FlightMeUp est en cours de développement, d'autres fonctionnalités arriveront. / FlightMeUp is under development, more features are coming.
