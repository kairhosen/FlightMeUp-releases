# FlightMeUp

Lance d'un clic les outils compagnons de Microsoft Flight Simulator : **Navigraph Charts** (avec import du dernier vol SimBrief), **BeyondATC** (démarrage automatique du vol) et **AutoFPS**.

Launches Microsoft Flight Simulator companion tools in one click: **Navigraph Charts** (with your latest SimBrief flight imported), **BeyondATC** (flight started automatically) and **AutoFPS**.

> **Bêta / Beta** : FlightMeUp est en cours de développement, d'autres fonctionnalités arriveront. / FlightMeUp is under development, more features are coming.

Téléchargez `FlightMeUp.exe` depuis la dernière [version](https://github.com/kairhosen/FlightMeUp-releases/releases) : aucune installation n'est nécessaire (Windows 10 2004 ou plus récent, x64).
